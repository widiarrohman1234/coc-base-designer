## Flow Genetic Algorith
```
Population
    ↓
Fitness Evaluation
    ↓
Selection
    ↓
Crossover
    ↓
Mutation
    ↓
New Population
    ↓
Repeat
    ↓
Best Solution
```

## GA simple
Optimasi posisi titik

Misalnya kita ingin mencari posisi (x, y) terbaik yang memaksimalkan nilai fungsi:8

$$
f(x,y)=−(x−3)^2−(y−5)^2+100
$$

Secara matematis kita sudah tahu optimum berada di:
```
x = 3
y = 5
fitness = 100
```

Tetapi Genetic Algorithm tidak diberi tahu jawaban tersebut.

GA harus menemukannya sendiri.


Pemahaman dasar:
- chromosome
- population
- fitness
- selection
- mutation
- generation
